# 安装图床

当前仓库以 Go 版本为主。PHP 相关文件仅保留给旧版本迁移使用。

## 直接运行

```bash
git clone https://github.com/Redstonexs/easyimages.git
cd easyimages
npm ci
npm run build
go build -o easyimage .
./easyimage
```

Windows：

```powershell
git clone https://github.com/Redstonexs/easyimages.git
cd easyimages
npm ci
npm run build
go build -o easyimage.exe .
.\easyimage.exe
```

访问 `http://localhost:8080/install/` 完成初始化。

## Docker Compose

```bash
git clone https://github.com/Redstonexs/easyimages.git
cd easyimages
docker-compose up -d
docker-compose logs -f
```

默认端口是 `8080`。如需更改端口，可在安装后修改 `config/config.json` 的 `port`，或调整 `docker-compose.yml` 的端口映射。

## 运行态目录

需要保留并备份的运行态目录：

- `config/config.json`
- `config/config.guest.json`
- `config/api_key.json`
- `config/install.lock`
- `i/`
- `admin/logs/`

这些路径已被 `.gitignore` 排除，不应提交到仓库。

## 从 PHP 版本迁移

```bash
cp /path/to/php/config/config.php config/
cp /path/to/php/config/config.guest.php config/
cp /path/to/php/config/api_key.php config/
npm ci
npm run build
go build -o easyimage .
./easyimage
```

`public/dist/` 是前端构建输出，本地直接运行前需要由 `npm run build` 生成；Docker Compose 会在镜像构建阶段自动生成。

详细说明见 [从PHP迁移到Go版本](从PHP迁移到Go版本.md)。

## WebP 转换依赖

如果启用 `webp_convert`，本机必须能执行 `cwebp`。Docker 镜像已安装 `libwebp-tools`，本地环境需要自行安装。
