> 推荐环境：Nginx + PHP≥7.0 + Linux

## PHP版本安装

#### windows:
- 下载简单图床 [最新版](https://github.com/icret/EasyImages2.0/archive/refs/heads/master.zip)|[稳定版](https://github.com/icret/EasyImages2.0/releases) 上传至web根目录

#### Linux:

- `git clone https://github.com/icret/EasyImages2.0.git` 至安装目录

- 赋予安装目录www:www和0755权限:
```shell
chmod -R 755 /安装目录
chown -R www:www /安装目录
```
- 有条件的建议开启OPcache

#### BT宝塔面板
- 1. 软件商店 → 一键部署 → 搜索`简单图床`一键部署稳定版
- 2. 使用上边的`Linux`方法搭建
- 3. 有条件的建议开启OPcache

## Go版本安装

Go版本具有更高性能、更低资源占用，推荐使用。

#### 直接运行

```bash
# 1. 克隆项目
git clone https://github.com/icret/EasyImages2.0.git
cd EasyImages2.0

# 2. 编译
go build -o easyimage

# 3. 运行
./easyimage
```

访问 http://localhost:8080 进行安装配置。

#### Docker部署

```bash
# 1. 克隆项目
git clone https://github.com/icret/EasyImages2.0.git
cd EasyImages2.0

# 2. 使用Docker Compose启动
docker-compose up -d
```

#### 从PHP版本迁移

如果已有PHP版本，可以无缝迁移到Go版本：

```bash
# 1. 备份数据
cp -r config/ config_backup/
cp -r i/ i_backup/

# 2. 编译配置转换工具
cd cmd/php2json
go build -o php2json

# 3. 转换配置文件
./php2json ../../config/config.php ../../config/config.json

# 4. 编译并运行Go版本
cd ../../
go build -o easyimage
./easyimage
```

详细迁移说明请参考：[从PHP迁移到Go版本](从PHP迁移到Go版本.md)
