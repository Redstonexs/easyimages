# 安全配置

## 上传目录

Go 版本不会执行上传目录中的脚本，但仍建议不要允许上传可执行文件扩展名，例如 `php`、`html`、`js`、`sh`。

如果反向代理或静态服务器会直接暴露 `i/`，可额外禁止脚本类文件访问。

Apache 示例：

```Apache
<FilesMatch "\.(?i:php|php3|php4|php5)">
Order allow,deny
Deny from all
</FilesMatch>
```

Nginx 示例：

```Nginx
location ~* ^/(config|docs|i|public)/.*\.(php|php5|html|js|sh)$ {
    deny all;
}
```

## API 和后台

- 不需要 API 上传时关闭 `apiStatus`。
- API token 应设置合理过期时间。
- 管理员密码安装后会使用 bcrypt 保存；迁移来的旧 SHA256 密码仍可验证。
- 生产环境建议通过 HTTPS 访问，避免 session cookie 和 token 明文传输。

## 登录验证码

后台「安全」中的「登录验证码」开启后，可选择四种类型：

| 类型 | 说明 | 需要外部服务 |
| --- | --- | --- |
| 内置数学题 | 服务端生成算式，答案用 HMAC-SHA256 签名，5 分钟过期 | 否 |
| Turnstile | Cloudflare Turnstile | 是（Cloudflare） |
| reCAPTCHA | Google reCAPTCHA | 是（Google） |
| Cap（自托管） | 开源自托管验证码，浏览器完成工作量证明 | 是（自行部署） |

任何一种外部验证码在密钥缺失时都会自动回退到内置数学题；验证服务不可用时一律拒绝登录，不会放行。

### 使用 Cap

Cap 需要先自行部署一个 Cap Standalone 实例（Docker + Redis/Valkey）：

```yaml
services:
  cap:
    image: tiago2/cap:latest   # 生产环境建议锁定具体版本
    ports:
      - "3000:3000"
    environment:
      ADMIN_KEY: <32 位以上随机字符串>
      REDIS_URL: redis://valkey:6379
      CORS_ORIGIN: https://图床域名   # 默认 * ，生产环境请收紧
      ENABLE_ASSETS_SERVER: "true"    # 由实例自身提供前端组件，见下
    depends_on:
      - valkey
  valkey:
    image: valkey/valkey:9-alpine
    command: valkey-server --save 60 1 --loglevel warning --maxmemory-policy noeviction
    volumes:
      - valkey-data:/data
volumes:
  valkey-data:
```

`--maxmemory-policy noeviction` 不能省略：令牌和会话依赖自身的 TTL 过期，被提前淘汰会导致验证异常。

部署后打开 `https://<实例地址>/`，用 `ADMIN_KEY` 登录，新建一个 Key，得到：

- **Site Key**（10 位十六进制）：公开值，会出现在页面上。
- **Secret Key**（`sk-` 开头）：**只在创建时显示一次**，仅服务端使用，请妥善保存。

在后台「安全」中填写 Cap 实例地址、Site Key、Secret Key 即可。Secret Key 只在保存时上传，不会回传到浏览器，留空表示保持原值。

注意不要把 `ADMIN_KEY` 填成 Secret Key —— 这是最常见的配置错误，会导致验证始终失败。

### 前端组件的加载地址

「Cap 组件地址」留空时，组件和 WASM 都从 Cap 实例自身加载
（`/assets/widget.js` 与 `/assets/cap_wasm_bg.wasm`），访客只会连接你自己的服务器。
这需要在容器上设置 `ENABLE_ASSETS_SERVER=true`，否则这两个地址会返回 404。

如果无法开启该选项，可以在「Cap 组件地址」中填写其他可访问的地址，例如
`https://cdn.jsdelivr.net/npm/@cap.js/widget@0.1.57`，或自行放到 `public/static/` 下引用。
需要注意 `cdn.jsdelivr.net` 在部分地区不可用，且此时 WASM 也会走该组件自带的默认地址。
