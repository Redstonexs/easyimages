# 常见问题

## Go 版本与 PHP 版本有什么区别？

Go 版本是当前主线：单二进制部署，无需 PHP 环境，不依赖数据库，配置和图片仍然基于文件存储。

## 首次访问应该打开哪个地址？

打开 `http://localhost:8080/install/` 完成初始化。安装完成后会生成 `config/config.json` 和 `config/install.lock`。

## 配置文件在哪里？

运行态配置在 `config/config.json`。上传者配置在 `config/config.guest.json`，API token 在 `config/api_key.json`。

## 为什么仓库里还有 `config/*.php`？

这些文件用于从旧 PHP 版本迁移。仓库内置默认 PHP 配置不会触发自动迁移；复制旧站点真实 PHP 配置后才会迁移。

## 如何从 PHP 版本迁移？

先备份旧站点的 `config/`、`i/` 和 `admin/logs/`，再复制旧 PHP 配置到当前仓库并启动 Go 服务。详情见 [从PHP迁移到Go版本](从PHP迁移到Go版本.md)。

## API 上传地址是什么？

当前 Go 版本是 `POST /api/index`，不是 `/api/index.php`。

```bash
curl -X POST http://localhost:8080/api/index \
  -F "image=@test.jpg" \
  -F "token=your_api_token"
```

## 后台地址是什么？

- 登录页：`/admin/index`
- 管理后台：`/admin/manager`

旧 PHP 风格的 `/admin/index.php` 和 `/admin/manager.php` 当前没有兼容路由。

## 图片路径是否兼容？

兼容。默认仍是 `/i/YYYY/MM/DD/file.ext`。

## 密码是否兼容？

兼容。迁移来的旧 SHA256 密码可以验证；新保存的密码使用 bcrypt。

## WebP 转换不生效怎么办？

确认已启用 `webp_convert`，并且系统能执行 `cwebp`。Docker 镜像已安装 `libwebp-tools`，本地运行需要自行安装。

## 上传失败怎么办？

检查这些项：

- `config/config.json` 中的 `maxSize` 和 `extensions`
- `i/` 目录是否可写
- 反向代理或防火墙是否限制上传大小
- 如果开启登录上传，确认浏览器 Cookie 未被拦截

## 升级后配置丢失怎么办？

运行态配置不会提交到 Git。升级前备份 `config/config.json`、`config/config.guest.json`、`config/api_key.json`、`config/install.lock`、`i/` 和 `admin/logs/`。
