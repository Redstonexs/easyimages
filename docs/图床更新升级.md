# 图床更新升级

## PHP版本升级

### 正常升级
1. 备份`config`目录和`上传文件目录`
2. **如果没有增加上传用户和API Token可以只保留`config.php`文件**
3. 将新程序下载至网站目录解压覆盖，然后将备份的文件替换既完成升级
4. 如果出现错误请在设置中把所有底部设置点击一次`保存`

### docker升级
1. 删除容器、镜像
2. 保留挂载在主机上的配置文件和上传文件夹
3. 重新执行一边docker安装代码

### 全新安装
1. 备份`上传文件目录`
2. 将新程序下载至网站目录解压覆盖，然后将备份的文件替换既重装完成

### 更新后显示当前版本与Github版本不一致？

- 将最新版按照[正常升级](#正常升级)操作
- 在系统信息中点击更新版本号

- 2.7.0 之前的版本：
-  删除`/admin/logs/verson`文件夹
   - 删除后并未获取版本? 答案：PHP没装curl或文件权限问题

- 2.6.5 之前的版本：
1. 打开`/config/config.php`文件找到当前版本号替换成最新版本号

*****
- 可以在设置->系统信息->图床信息中查看当前版本和Github最新版本
- 每个月获取2次，因为PHP不能定时任务，所以不一定能正确获取

## 从PHP版本迁移到Go版本

### 迁移优势

Go语言版本具有以下优势：
- **更高性能** - Go语言原生性能优于PHP
- **更低资源占用** - 内存和CPU占用更低
- **更简单部署** - 单二进制文件，无需PHP环境
- **Docker支持** - 官方Docker镜像
- **完全兼容** - 数据和配置无缝迁移

### 快速迁移

#### 1. 备份数据

```bash
# 备份配置文件
cp -r config/ config_backup/

# 备份上传的图片
cp -r i/ i_backup/

# 备份管理后台日志
cp -r admin/logs/ admin_logs_backup/
```

#### 2. 转换配置文件

```bash
# 编译转换工具
cd cmd/php2json
go build -o php2json.exe

# 转换配置文件
./php2json.exe ../../config/config.php ../../config/config.json
./php2json.exe ../../config/config.guest.php ../../config/config.guest.json
./php2json.exe ../../config/api_key.php ../../config/api_key.json
```

#### 3. 部署Go版本

```bash
# 方式一：直接运行
go build -o easyimage
./easyimage

# 方式二：Docker部署
docker build -t easyimage .
docker run -d -p 8080:8080 \
  -v $(pwd)/config:/app/config \
  -v $(pwd)/i:/app/i \
  easyimage

# 方式三：Docker Compose
docker-compose up -d
```

#### 4. 验证迁移

- 访问管理后台确认配置正确
- 测试上传功能
- 确认原有图片可以正常访问

### 详细迁移说明

完整的迁移指南请参考：[从PHP迁移到Go版本](从PHP迁移到Go版本.md)

### 回滚方案

如果需要回滚到PHP版本：

```bash
# 停止Go版本
pkill easyimage

# 恢复PHP文件
cp -r php_backup/* ./

# 启动PHP版本
```

## Go版本升级

### 直接升级

```bash
# 1. 备份配置和数据
cp -r config/ config_backup/
cp -r i/ i_backup/

# 2. 下载新版本
git pull origin main

# 3. 重新编译
go build -o easyimage

# 4. 重启服务
pkill easyimage
./easyimage
```

### Docker升级

```bash
# 1. 停止并删除旧容器
docker stop easyimage
docker rm easyimage

# 2. 重新构建镜像
docker build -t easyimage .

# 3. 启动新容器
docker run -d -p 8080:8080 \
  -v $(pwd)/config:/app/config \
  -v $(pwd)/i:/app/i \
  --name easyimage \
  easyimage
```

### Docker Compose升级

```bash
# 1. 停止服务
docker-compose down

# 2. 重新构建并启动
docker-compose up -d --build
```

- 必需扩展：Fileinfo, iconv, zip, mbstring, openssl

- 最低Go版本：1.21
- 支持平台：Linux, Windows, macOS
- Docker支持：是

## 常见升级问题

### 升级后配置丢失？

- 检查是否正确备份了config目录
- 确认配置文件路径正确

### 升级后图片无法访问？

- 检查图片目录权限
- 确认path配置正确

### 升级后无法登录？

- 清除浏览器Cookie
- 检查密码哈希是否正确
