# 图床更新升级

## Go 版本升级

升级前备份运行态数据：

```bash
cp -r config/ config_backup/
cp -r i/ i_backup/
cp -r admin/logs/ admin_logs_backup/
```

直接运行版本：

```bash
git pull origin master
go build -o easyimage .
pkill easyimage
./easyimage
```

Docker Compose：

```bash
docker-compose down
docker-compose up -d --build
docker-compose logs -f
```

Docker CLI：

```bash
docker stop easyimage
docker rm easyimage
docker build -t easyimage .
docker run -d \
  --name easyimage \
  -p 8080:8080 \
  -v "$PWD/config:/app/config" \
  -v "$PWD/i:/app/i" \
  -v "$PWD/admin/logs:/app/admin/logs" \
  easyimage
```

## 从 PHP 版本迁移到 Go 版本

```bash
cp /path/to/php/config/config.php config/
cp /path/to/php/config/config.guest.php config/
cp /path/to/php/config/api_key.php config/
go build -o easyimage .
./easyimage
```

完整说明见 [从PHP迁移到Go版本](从PHP迁移到Go版本.md)。

## 回滚到 PHP 版本

如果自动迁移后需要回滚：

```bash
pkill easyimage
cp config/php_backup/config.php config/
cp config/php_backup/config.guest.php config/
cp config/php_backup/api_key.php config/
rm config/config.json config/config.guest.json config/api_key.json config/install.lock
```

然后按旧 Web 服务器配置启动 PHP 版本。

## 兼容性

- Go 版本最低要求：Go 1.21
- Docker 镜像内置 `libwebp-tools`，支持 WebP 转换
- 本地启用 WebP 转换时需要 `cwebp` 在 `PATH` 中
- 当前 Go API 路由为 `/api/index`，没有 `/api/index.php` 兼容路由

## 常见升级问题

### 升级后图片无法访问

检查 `config/config.json` 的 `path`，并确认 `i/` 目录已挂载或复制到新环境。

### 升级后无法登录

清除浏览器 Cookie 后重试，并确认 `config/config.json` 和 `config/install.lock` 没有丢失。

### WebP 转换失败

确认 `cwebp` 可执行。Docker 环境已内置，本地环境需要自行安装。
