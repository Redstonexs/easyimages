## Go版本官方Docker部署

Go版本提供官方Docker镜像，部署更简单：

### Dockerfile

```dockerfile
FROM golang:1.21-alpine AS builder
WORKDIR /build
COPY . .
RUN CGO_ENABLED=0 go build -o easyimage .

FROM alpine:latest
WORKDIR /app
COPY --from=builder /build/easyimage .
COPY --from=builder /build/public ./public
COPY --from=builder /build/config ./config
EXPOSE 8080
CMD ["./easyimage"]
```

### docker-compose.yml

```yaml
version: '3.8'
services:
  easyimage:
    build: .
    container_name: easyimage
    restart: unless-stopped
    ports:
      - "8080:8080"
    volumes:
      - ./config:/app/config
      - ./i:/app/i
      - ./public:/app/public
      - ./admin/logs:/app/admin/logs
    environment:
      - TZ=Asia/Shanghai
```

### 快速启动

```bash
# 克隆项目
git clone https://github.com/icret/EasyImages2.0.git
cd EasyImages2.0

# 使用Docker Compose启动
docker-compose up -d

# 查看日志
docker-compose logs -f
```

### 从PHP版本迁移到Docker

```bash
# 1. 备份PHP版本数据
cp -r config/ config_backup/
cp -r i/ i_backup/

# 2. 编译配置转换工具
cd cmd/php2json
go build -o php2json

# 3. 转换配置文件
./php2json ../../config/config.php ../../config/config.json

# 4. 启动Docker
cd ../../
docker-compose up -d
```

详细迁移说明请参考：[从PHP迁移到Go版本](从PHP迁移到Go版本.md)
